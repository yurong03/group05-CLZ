
# 指令說明（Instructions）

本資料夾用於存放本專案所選指令的相關說明文件。

## 指令資訊

- 指令名稱：CLZ（Count Leading Zeros，前導零計數）
- 對應檢查點：CP1
- 資料寬度：32 位元
- 輸入型態：32 位元無號整數
- 輸出內容：從最高位元開始連續出現的 0 的數量

## 指令功能

CLZ 用於計算 32 位元無號整數，從最高位元開始連續出現的前導零數量。

例如，輸入 `0x00000001` 時，前面有 31 個連續的 0，因此回傳 `31`。

當輸入為 `0x00000000` 時，依照本專案規格，回傳 `32`。
